- **目标读者**：金融机构内部决策层 / 监管研究部门 / 主权基金研究岗

- **核心论点**（待实证检验后定稿）：
  1. 摩洛哥伊斯兰金融对房地产融资的影响表现为**合同形式重写**，而非"消除融资成本"。
  2. 参与式房地产融资是**监管内嵌的补充板块**，与传统房地产信贷并行而非竞争性替代。
  3. 参与式板块对政策利率的响应模式可能不同于传统信贷——这是检验"避险渠道"假说的关键。

**采集风险**（提前识别）：
- BAM 月度统计页面历史回溯通常只保留近 12–24 个月，早期数据需要逐期下载的归档页面或历史 PDF 报告。
- HCP 房价指数可能仅有季度或年度颗粒度，届时降频处理或剔除该控制变量。
- 政策利率在 2020–2022 区间段多次调整，需逐日序列整理为月度均值。

## 5. 方法论详述

### 5.1 CAGR 与渗透率（H1）

- **CAGR**：分别计算 2018-2025 房地产 murabaha 与传统房地产信贷的复合年均增长率
- **渗透率**：月频计算 `murabaha_immobilier / (murabaha_immobilier + credit_immobilier_conventionnel)`，年度均值汇总
- **可视化**：双轴时间序列图（左轴余额、右轴渗透率）、年度 CAGR 对比柱状图

### 5.2 结构性断点检验（H2）

- **Chow 检验**：预设断点为 2020-03（COVID 冲击）与 2022-12（加息周期开启）。对样本期分别拟合单一回归与分段回归，比较 RSS。
- **Bai-Perron**：不预设断点，让数据决定最优断点数量（上限设为 3 个，BIC 选择），与 Chow 形成交叉验证。
- **报告内容**：断点位置、95% 置信区间、断点前后子样本均值差、统计显著性。

### 5.3 OLS 回归（H3）

- **主回归**（月度频度）：
  ```
  Δlog(MRE_t) = α + β1·r_t + β2·Δlog(HPI_t) + β3·Δlog(CCRE_t) + ε_t
  ```
  - `MRE`：房地产 murabaha 余额
  - `CCRE`：传统房地产信贷余额
  - `r`：BAM 政策利率
  - `HPI`：房价指数
- **标准误**：Newey-West（HAC）修正自相关与异方差
- **稳健性**：
  1. 子样本（COVID 前 / COVID 后）
  2. 替代控制变量（用传统信贷增速差替代水平）
  3. 加入通胀作为额外控制
- **核心比较**：在传统信贷方程中替换被解释变量为 `Δlog(CCRE)`，比较两个方程的政策利率系数是否显著不同（Wald 检验）

### 5.4 Granger 因果检验（H4）

- **步骤 1**：对 `Δlog(MRE)`、`Δlog(CCRE)` 与 `r` 分别进行 ADF 单位根检验，确认平稳性
- **步骤 2**：若非平稳，做一阶差分或取同比增长率；记录变换后的检验结果
- **步骤 3**：用 AIC/BIC/HQ 选择 VAR 滞后阶（上限 6）
- **步骤 4**：Granger 因果检验——分别检验：
  - `r` → `Δlog(MRE)`
  - `r` → `Δlog(CCRE)`
- **避险渠道假说的判定**：
  - 若 `r` Granger-cause `Δlog(CCRE)` 强于 `r` Granger-cause `Δlog(MRE)`，则参与式板块对政策利率反应较钝，支持"避险渠道"叙事
  - 若两者响应强度接近，则参与式板块与传统信贷行为同步，未呈现避险特征

## 7. 风险与局限（前瞻）

| 风险 | 影响 | 缓解方案 |
|---|---|---|
| 月度样本量 ~84，对 VAR(4+) 偏紧 | Granger 检验功效不足 | 降频到季度（n≈28）作对照；限制最大滞后阶 |
| BAM 历史数据回溯不全 | 样本期缩短 | 用历史 BAM 年度报告中的年度数据回填空缺月份；明确说明插值方法 |
| 房价指数颗粒度不足 | 回归中 HPI 控制变量失效 | 改为季度或剔除，用利率 + 通胀替代 |
| 参与式板块规模小，绝对量级差异大 | 双轴图视觉误导 | 双轴 + 标准化图 + 渗透率图三图并列 |
| 政策利率在样本期内单调上行 | 多重共线性风险 | 计算 VIF；考虑用利率差分替代水平 |
| OLS 因果推断薄弱 | 仅得相关性 | 文中明确表述为"响应关系"而非因果 |
